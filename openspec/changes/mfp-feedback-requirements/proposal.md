# MFP-Feedback 系统需求方案

## 方案概述

本变更添加了 MFP-Feedback 系统的核心需求，这是一个制造计划回传系统，旨在跟踪发动机零部件制造过程的进度，监控供应商交付风险，确保过程可控和可追溯。

## 变更详情

### 新增需求

- **FR1: 采购订单分发** - 系统应基于 ERP 数据自动生成制造任务并分发给供应商。
- **FR2: 生产计划进度反馈** - 系统应允许供应商更新制造进度并实时跟踪任务状态。
- **FR3: 用户角色管理** - 系统应实现具有不同权限级别的基于角色的访问控制。

### 修改需求

- 无

### 移除需求

- 无

## 实现影响

- **前端**：Vue 3 + TypeScript + Vue-Vben-Admin
- **后端**：Nest.js + TypeScript
- **数据库**：MySQL 8.0
- **流程引擎**：Camunda 7.24

## 风险评估

- **低风险**：本变更仅添加需求，不修改现有功能。
- **依赖**：需要与 ERP 系统集成以获取采购订单数据。

## 审批流程

- **审核人**：系统架构师
- **审批人**：项目经理
